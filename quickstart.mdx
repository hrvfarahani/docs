---

برای کار با API فروشندگان دیجی‌کالا به یک حساب فروشندگی فعال و یک کلید API نیاز دارید. در این راهنما با دو درخواست، اتصال را آزمایش می‌کنید و سفارش‌هایتان را دریافت می‌کنید.

<Steps>
  <Step title="ساخت کلید API">
    کلید خود را مطابق [راهنمای احراز هویت](/authentication) از پنل فروشندگان بسازید.
  </Step>
  <Step title="آزمایش اتصال">
    پروفایل فروشنده را بخوانید. پاسخ موفق یعنی کلید شما درست کار می‌کند:

    ```bash
    curl "https://seller.digikala.com/api/v1/profile/" \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```
  </Step>
  <Step title="دریافت سفارش‌ها">
    سفارش‌های تأییدشده را دریافت کنید:

    ```bash
    curl -G "https://seller.digikala.com/api/v1/orders/" \
      -H "Authorization: Bearer YOUR_API_KEY" \
      --data-urlencode "search[order_status]=confirmed"
    ```
  </Step>
</Steps>
