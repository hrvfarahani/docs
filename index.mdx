Open API فروشندگان دیجی‌کالا (نسخه v1) رابطی برنامه‌نویسی است که فروشندگان می‌توانند با آن سیستم‌های خود را به پنل فروشندگی دیجی‌کالا متصل کنند. در این مستندات با نحوه احراز هویت، ارسال اولین درخواست و ساختار مرجع API آشنا می‌شوید.
