API فروشندگان دیجی‌کالا درخواست‌ها را با کلید API حساب فروشندگی شما احراز هویت می‌کند. کلید را از پنل فروشندگان می‌سازید و در هدر `Authorization` هر درخواست ارسال می‌کنید.

## ساخت کلید API

<Steps>
  <Step title="ورود به پنل">
    وارد [پنل فروشندگان دیجی‌کالا](https://seller.digikala.com) شوید.
  </Step>
  <Step title="باز کردن بخش API">
    روی آیکون پروفایل (آدمک) بالای صفحه کلیک کنید و از منو گزینه **API** را انتخاب کنید.
  </Step>
  <Step title="ایجاد کلید">
    روی **ایجاد کلید جدید** کلیک کنید. کلید ساخته و نمایش داده می‌شود و با آیکون کپی کنار آن می‌توانید کپی‌اش کنید. می‌توانید هر تعداد کلید بسازید و زمان ایجاد و آخرین استفاده هر کلید را ببینید.
  </Step>
</Steps>

<Accordion title="گزینه API در منو نیست یا خطا می‌دهد">
  API برای همه فروشندگان به‌صورت پیش‌فرض فعال نیست. برای فعال‌سازی:

  1. به **درخواست پشتیبانی** بروید و **ثبت درخواست پشتیبانی** را بزنید.
  2. دسته‌بندی **عملکرد فروشندگان** و موضوع **سایر درخواست‌ها** را انتخاب کنید و **تایید و ادامه** را بزنید.
  3. عنوان را «فعالسازی API» بگذارید، درخواست خود را در متن بنویسید و آن را ثبت کنید.

  فعال‌سازی از چند دقیقه تا حداکثر ۴۸ ساعت طول می‌کشد.
</Accordion>

## ارسال کلید

کلید را در هدر `Authorization` قرار دهید:

```bash
curl "https://seller.digikala.com/api/v1/profile/" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

<Warning>
  کلید API دسترسی به پنل شما را می‌دهد. آن را در کد سمت کاربر یا مخازن عمومی قرار ندهید و برای هر سرویس متصل یک کلید جداگانه بسازید.
</Warning>

## خطاهای رایج

<AccordionGroup>
  <Accordion title="401 با پیام Invalid token!">
    کلید ارسال نشده، اشتباه کپی شده یا دیگر معتبر نیست. کلید را دوباره از پنل کپی کنید یا کلید جدیدی بسازید.
  </Accordion>
</AccordionGroup>
