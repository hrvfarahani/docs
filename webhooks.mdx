title: "ثبت وب‌هوک برای کلید API در پنل فروشندگان دیجی‌کالا"
sidebarTitle: "وب‌هوک‌ها"
description: "راهنمای ساخت وب‌هوک برای هر کلید API در پنل فروشندگان دیجی‌کالا، دریافت توکن امنیتی وب‌هوک و استفاده از آن در سرویس دریافت‌کننده رویدادها."
---

پنل فروشندگان دیجی‌کالا اجازه می‌دهد برای هر کلید API یک یا چند وب‌هوک ثبت کنید تا رویدادها به آدرس سرور شما ارسال شوند. هر وب‌هوک یک توکن امنیتی دارد که سرویس شما با آن درخواست‌های دیجی‌کالا را شناسایی می‌کند.

<Steps>
  <Step title="باز کردن صفحه کلیدها">
    در پنل فروشندگان روی آیکون پروفایل (آدمک) کلیک کنید و گزینه **API** را بزنید تا صفحه **کلیدهای API شما** باز شود.
  </Step>
  <Step title="باز کردن فهرست وب‌هوک‌ها">
    در ستون عملیات کلید موردنظر، روی آیکون **لیست وب‌هوک‌ها** کلیک کنید.
  </Step>
  <Step title="ایجاد وب‌هوک">
    در صفحه **WebHook های ثبت شده شما** روی **ایجاد webhook جدید** کلیک کنید، آدرس URL سرور خود را وارد کنید و **ایجاد** را بزنید.
  </Step>
  <Step title="کپی توکن امنیتی">
    روی توکن امنیتی ساخته‌شده کلیک کنید تا کپی شود و آن را در سرویس دریافت‌کننده ذخیره کنید.
  </Step>
</Steps>

<Note>
  ساختار رویدادهای ارسالی وب‌هوک در منابع عمومی مستند نشده است. برای جزئیات به [مستندات Swagger دیجی‌کالا](https://seller.digikala.com/open-api/v1/doc/#/) مراجعه کنید.
</Note>
