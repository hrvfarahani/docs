مرجع API فروشندگان دیجی‌کالا اندپوینت‌های سفارش، تنوع کالا و پروفایل فروشنده را پوشش می‌دهد. همه درخواست‌ها به [احراز هویت](/authentication) با کلید API نیاز دارند.

## آدرس پایه

```text
https://seller.digikala.com/api/v1
```

## قراردادها

- درخواست‌ها و پاسخ‌ها با قالب JSON مبادله می‌شوند. برای درخواست‌های دارای بدنه، هدر `Content-Type: application/json` را بفرستید.
- فیلترهای فهرست‌ها با الگوی `search[field]` ارسال می‌شوند، مثلاً `search[order_status]=confirmed`.
- فیلترهای چندمقداری به‌صورت فهرست جداشده با کاما ارسال می‌شوند.
- مسیرها با `/` پایانی تعریف شده‌اند.
